# GitHub Workflow

## 1. Repository Purpose
This repository acts as the central version control and deployment source for "Project 1 - Quran Academy". It is designed to be easily cloneable for future client deployments and acts as a pristine portfolio asset.

## 2. Recommended Repository
- **Remote Link:** `https://github.com/mramzan579/Quran-Academy.git`
- **Name:** `Quran-Academy`

## 3. Recommended Commit Structure
When maintaining this project, follow this clean commit structure:
- `Initial Commit`: Baseline HTML, CSS, and JS structure.
- `Portfolio Assets Added`: Screenshots and markdown documentation generated.
- `Netlify Deployment Ready`: Final preparation of the deployment ZIP.
- `Final Outreach Version`: Project marked as complete and frozen.

## 4. Basic Versioning Strategy
- **v1.0.0**: Stable, fully static demo deployment. Frozen state.
- **v1.x.x**: Reserved only for critical bug fixes.
- No new features will be added to this branch. For custom client requests, a new branch or duplicate repository should be created.
